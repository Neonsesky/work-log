Google Sheet connection

Your data lives in a Google Sheet you own. The app talks to it through a small Apps Script. Set it up once per sheet.

1Create a blank sheet at sheets.google.com. Name it anything you like.
2Open Extensions → Apps Script, delete what's there, paste the script below and press Ctrl+S.
3Deploy → New deployment → gear icon → Web app. Execute as Me, access Anyone. Deploy, authorize, copy the web app URL.
4Paste that URL here. If you ever update the script, redeploy with Manage deployments → New version.

Install as an app

Runs full screen with its own icon, on your phone and your computer.

PCIn Chrome or Edge, click the install icon at the right end of the address bar, or open the menu and choose Install Work Log.
AndAndroid Chrome: menu ⋮ → Add to Home screen (or "Install app").
iOSSafari: Share → Add to Home Screen.
